# Conor Duffy's Digital Garden

Build a whimsical, polished personal website for Conor Duffy.

This is not a traditional CV site. It should feel like a personal digital garden, field notebook and proof-of-work site for someone who thinks in systems, stories and enterprise software.

The goal is to get to a clean MVP quickly, with room to improve over time.

Primary concept:
“Enterprise problems, human-shaped solutions.”

Personality:
Warm, smart, Irish, curious, lightly whimsical, commercially aware. It should feel personal and charming, not corporate, not startup-bro, not generic portfolio template.

About Conor:
Conor Duffy is an Irish enterprise solutions engineer based in London. He has a background in accounting, consulting, Salesforce and Slack. He works at the intersection of enterprise software, AI adoption, customer storytelling, value-led solution design and practical architecture. He is interested in how teams turn messy ideas into useful systems.

Design direction:
Take inspiration from personal digital gardens, playful technical blogs and polished personal sites. The site should feel crafted, warm and alive, with subtle details, cards, light motion and small moments of personality. Keep it simple and fast for MVP. Avoid heavy 3D, complicated animations, corporate stock imagery or over-designed SaaS landing page clichés.

Visual style:

Clean typography

Soft, warm colour palette

Card-based sections

Subtle whimsical icons or doodle-style details

Rounded corners

Light animations / hover states

A homepage portrait area using the attached photo of me

Tasteful abstract shapes where images are missing

Fully responsive mobile design

Fast and easy to edit

How I Work page:
Create a simple visual framework called “How I Work”.

Use these steps:

Start with the user journey

Map the systems

Expose the trade-offs

Tie technical choices to business value

Build the smallest credible version

Make it extensible later

Each step should have a short explanation in plain English. Keep the tone thoughtful and practical.

v2: Copy, tone and visual design refined

MVP requirements:

Make it liveable and polished enough to publish quickly

Keep the code clean and easy to change

Avoid overbuilding

Make the homepage the strongest part

Make the copy sound human, not AI-generated

Leave obvious places to improve later

Prioritise speed to MVP over perfection
